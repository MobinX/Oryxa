# Release APK Directory

This directory stores the compiled production Android APK generated by GitHub Actions.

- When a commit message contains `{{native}}`, the GitHub Actions workflow rebuilds the full native Flutter application in release mode and writes the signed APK here (`app-release.apk`).
- You can download this APK directly from GitHub or use `git pull` to install it on your Android testing device via ADB:
  ```bash
  adb install -r apk/app-release.apk
  ```
